# Typography Studio: plugin en español

Versión 0.4.1. Incluye la skill `typography-design-review`, instrucciones,
diez referencias traducidas, plantillas y herramientas locales opcionales.

Invocá `$typography-design-review` en Codex. Podés pedir una fuente nueva,
revisión de dibujo y espaciado, pruebas de una familia o jerarquía adaptable.
Aportá la fuente editable o exportada y su uso previsto cuando estén disponibles.

El ZIP `typography-studio-0.4.1-plugin-es.zip` tiene instrucciones y metadatos
de interfaz en español. Conserva el mismo identificador y capacidades que
la edición inglesa. Elegí una edición al instalar. El plugin del marketplace
incluye los recursos en ambos idiomas y sigue el idioma del usuario.

El generador incluido en el ZIP español produce pruebas en español por
defecto. `--language es` o `--language en` permiten elegir.
No requiere servidor MCP ni cuenta propia: las herramientas opcionales
trabajan sobre archivos aportados y generan salidas locales nuevas.

MIT cubre este paquete; las fuentes conservan sus licencias.
Las referencias están atribuidas. La revisión visual exige abrir imágenes.
La distribución pública en GitHub y la presentación al catálogo de OpenAI
son pasos distintos.
