# Practice, feedback and honest evaluation

Treat this as a repeatable design process, not training the model or awarding
professional credentials. Preserve the first judgment when feedback corrects it.

## Exercises

| Exercise | Compare | Observe |
| --- | --- | --- |
| H/O weight | Equal geometric thickness vs optical compensation | Perceived stem/round weight and overshoot |
| n/o rhythm | Silhouettes and nnnn/oooo/nonono | Shoulder, counter, interior/shared white |
| Bézier repair | Initial, tangent-repaired and silhouette versions | A smooth connection can retain a bulge |
| e/s structure | Alternatives with fixed metrics, in words | Opening, waist, transitions and terminal voice |
| Sidebearings | Fixed forms with metric alternatives | Base rhythm before exceptional pairs |
| Punctuation | Abbreviations, point/comma separately | Attachment and following word space |
| Recognition | Covered confusions in real words/data | Distinction at actual sizes and voice tradeoffs |
| Hierarchy | Same content across roles/viewports | Apparent size, leading, breaks and measure |
| Family extremes | Thin/heavy and unnamed axis positions | Counters, joins, marks, rhythm and regressions |

These are proposed exercises, not previously measured successful cases.
State the predicted effect before viewing the answer. Explain a concrete
benefit, regression or failed hypothesis with actual images afterward.

## Evaluate the workflow

Build a corpus of defects, accepted examples and unreviewed examples with
permission and provenance. Separate role, face, size, platform and criterion.
Reserve examples for later assessment rather than repeatedly using the same
recently studied cases as a test of generalization.

Record localized defect/evidence, severity, initial judgment, human correction
if present, recommended change, subsequent result and real coverage. A/B
preference is not comprehensive acceptance; a technical fixture is not an
aesthetic positive case.

When there are enough independent cases, report serious omissions, false
acceptances/rejections and unassessed cases separately. Do not derive a quality
score or accuracy claim from a few familiar examples or automated font checks.
Human feedback is useful; do not add an unsolicited specialist-signature gate.
