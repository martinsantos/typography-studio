# Contribuir

[English](https://github.com/martinsantos/typography-studio/blob/v0.4.2/CONTRIBUTING.md). Mantené el método independiente de marcas y modas.
Proponé un issue o pull request con problema, hipótesis, evidencia con licencia
o titularidad propia, condiciones de renderizado y cambio acotado.
Usá ejemplos genéricos y excluí archivos confidenciales.

Separá requisitos de formato, decisiones de proyecto, juicio visual
y resultados medidos con personas. Citá fuentes primarias cuando sea posible
y señalá citas secundarias o material inaccesible.
Los tamaños iniciales no son normas universales de lectura.

Mantené equivalentes las instrucciones y recursos de ambos idiomas.
Conservá identificadores de skill/plugin, campos JSON, comandos, códigos
de estado y valores numéricos. Traducí textos de presentación y explicaciones.
Los corpus mantienen los mismos textos de diagnóstico y marcas Unicode;
la localización cambia rótulos y el idioma declarado.

Para auxiliares, probá una fuente con licencia fuera del paquete,
caracteres ausentes y rechazo de salidas existentes. Abrí las capturas antes
de informar hallazgos. Registrá por separado ejercicios propuestos y ejecutados.

Ejecutá validación, comprobación de localización y prueba del publicador,
y empaquetá en una carpeta nueva. No agregues fuentes, PDF licenciados,
credenciales, entornos ni cachés de navegador.
La prueba del publicador usa Git local real y GitHub simulado, sin publicación.
