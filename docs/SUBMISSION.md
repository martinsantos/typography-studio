## Description

Build and refine typefaces from a brief: control glyphs, optical corrections,
spacing, kerning, weights, italics, variable families and exports. Review actual
rendered words and responsive hierarchy, with clear attribution and evidence.
Includes optional local proofing scripts and Latin English/Spanish exercises.
Requires image inspection for visual conclusions and suitable font-editing tools
for source changes. Technical checks do not certify aesthetics, reading speed
or untested platforms.

## Starter prompts

1. Help me design a typeface from its brief and review control glyphs in real words.
2. Review my font's curves, spacing, punctuation and hierarchy using actual rendered proofs.

## Behavior and privacy

One skill; no MCP servers, hooks, account connection, telemetry or automated
uploads. Optional scripts read user-selected fonts/corpora and create new local
metadata, HTML and screenshots. Proof HTML embeds the font and must be treated
under its license and confidentiality. The capture helper blocks external
requests. Research requested by the user can use available host tools subject
to that host's permissions; this package does not implement an external service.

The host model must open images before visual conclusions. The skill cannot
make an image-blind agent a visual reviewer, replace a font editor, demonstrate
reader outcomes without participants or certify untested native platforms.
