Typography Studio 0.4.0 is the first standalone brand-independent edition of
the type-design and visual-review workflow.

It includes control-glyph construction guidance, optical review, spacing and
kerning, family/export checks, responsive composition, attributed educational
sources, generic English/Spanish exercises and optional local proofing helpers.
Actual rendered line lengths and renderer font use are reported separately
from visual judgments. No font binaries or third-party PDFs are distributed.

MIT license. Install the repo marketplace or the standalone skill. The plugin
ZIP is also prepared for a separate OpenAI verified-publisher submission;
this GitHub release does not imply directory approval or perfect font quality.
