# Typography Studio 0.4.1 — English and Spanish

Complete Spanish skill instructions, ten translated references, templates,
interface metadata and localized proof labels, load states and coverage warnings.
`--language es` and `--language en` select the proof interface. The Spanish
packages select Spanish by default while preserving the bilingual diagnostic
corpus, actual font, metrics, install identities and executable helpers.

Six verified ZIPs provide skill, plugin and marketplace in both languages.
Version 0.4.0 remains unchanged. MIT license. OpenAI directory submission
and review remain separate from this public GitHub release.
