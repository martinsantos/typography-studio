# Typography Studio privacy notice

Publisher: Martín Santos. Updated 2026-10-08.
[Español](PRIVACY.es.md).

## Scope

Typography Studio distributes an agent skill and optional local proofing
helpers. The package includes no publisher-operated server, account
connection, analytics, telemetry or automatic upload service.

The helpers read the font and corpus selected by the user and create local
metadata, HTML and screenshots. Proof HTML embeds the selected font.
The capture helper blocks external network requests. These helpers do not
send the selected fonts or proofs to the publisher.

## Host tools and installation

The ChatGPT, Codex or other agent host may process information supplied in
conversations or through its tools under that service's privacy settings
and policies. Requested research may use the host's browser or connected
tools. Review the destination and permissions before sharing confidential
fonts, client work or other personal information through those tools.

GitHub handles repository downloads and interactions. If you install using
the separate Skills CLI, its own telemetry policy applies; see the
[CLI documentation](https://www.skills.sh/docs/cli).

## Local outputs and support

The user controls local generated files and can delete them with their
normal file tools. Embedded fonts and proof images retain the source
material's license and confidentiality requirements.

Support uses [public GitHub Issues](https://github.com/martinsantos/typography-studio/issues).
Do not include private fonts, credentials, personal data or confidential
client files in a public issue. The publisher can see the information you
choose to post there.
